# Objetos Perdidos ITT Unidad Tomás Aquino

Plataforma web para la comunidad del **Instituto Tecnológico de Tijuana de la unidad Tomás Aquino** donde puedes consultar los objetos perdidos que han sido encontrados dentro del campus. Si perdiste algo, aquí puedes buscarlo y pasar a recogerlo a las casetas de guardias.

**Visita la página:** [pepinisillo.github.io/-objetos-perdidos-itt](https://pepinisillo.github.io/-objetos-perdidos-itt/)

---

## ¿Cómo funciona?

Los objetos que se encuentran dentro del campus son registrados en la plataforma con foto, categoría y ubicación donde se encontraron. Tú solo tienes que entrar a la página y buscar si tu objeto aparece.

### Buscar un objeto

1. Entra a la página web.
2. Usa la **barra de búsqueda** para escribir lo que perdiste (por ejemplo: "audífonos", "calculadora", "chamarra").
3. También puedes filtrar por **categoría** usando el menú desplegable:
   - **Electrónicos** — celulares, audífonos, cargadores, USBs, etc.
   - **Ropa y Accesorios** — chamarras, gorras, lentes, mochilas, etc.
   - **Cuadernos y Materiales** — libretas, libros, lápices, etc.
   - **Otros** — llaves, termos, tuppers, credenciales, etc.
4. Si ves tu objeto, haz **click en la imagen** para ver los detalles: descripción, lugar donde se encontró y fecha.
5. Pasa a recogerlo a la **caseta de guardias** correspondiente.

### Explorar por categorías

En la sección de categorías puedes ver las fotos más recientes de cada tipo de objeto. Si le das click a una categoría, se filtran automáticamente los objetos de ese tipo.

### Paginación

Si hay muchos objetos registrados, la página los divide automáticamente. Puedes elegir cuántos objetos ver por página (10, 20, 50 o 100) y navegar entre páginas con los botones de "Anterior" y "Siguiente".

### Zoom de imagen

Cuando abres el detalle de un objeto, puedes hacer click en la imagen para verla en pantalla completa y asegurarte de que es el tuyo.

## Funciona en celular

La página está diseñada para verse bien tanto en computadora como en celular, así que puedes revisarla desde donde sea.

| Firebase Auth | Autenticación para el panel de administración |
| GitHub Pages | Hosting de la página |
